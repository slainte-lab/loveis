# Love is… — игра для пар

Одностраничная игра «Кто лучше знает свою половинку». Без сервера и БД: синхронизация телефонов через публичный MQTT-брокер, состояние хранит большой экран (ноутбук).

- Ведущий открывает страницу на ноутбуке → «Создать игру».
- Гости сканируют QR с экрана. Админ на телефоне вводит имя и PIN (⚙ на большом экране).
- Вопросы правятся в начале `index.html` (массив `QS`).
